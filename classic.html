Progress

Your progress Ideal path Next 3 sessions

Progress score = level plus the position of your last set inside the rep range (level 7 with a last set of 8 in a 5–10 range is 6.6). The last set is the one that catches up last. The ideal path follows the same rule as your targets: one rep on one set per session, set 1 first, until all sets match, then set 1 again. When every set reaches the maximum, the next level starts at the minimum reps. Dotted = the next 3 sessions at your average training interval.

Settings

Experience

Beginner: one set less on every exercise and 8–15 reps for rep exercises. Pro: one set more everywhere, the rep ranges stay. Values you set yourself per exercise are kept.

Training phase

The phase sets the rep range of the rep exercises. Holds are not affected, beginners keep 8–15, and values you set per exercise are kept.

Training focus

Upper: three upper-body exercises and one leg exercise per Push or Pull day. Lower: the other way round, with leg exercises first, one easy upper-body exercise (knee push-ups or Australian pull-ups) and lateral raises and face pulls as extras. Days you already logged keep their exercises. The setting applies to days you plan from now on.

Hobby / activity

The activity trains these muscle groups. Exercises of the selected groups are skipped on the day before and on the day of the activity (set per day in the log).

Exercises

Band 5 = strongest assistance, Band 1 = lightest. Levels run from top (easy) to bottom (hard). Empty fields are skipped, and trailing fields may stay empty. Inserting or deleting levels shifts the numbering, so check the start level afterwards.
